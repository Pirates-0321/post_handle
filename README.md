# 163邮箱重点邮件助手 (post_handle)

一个 Chrome / Edge 浏览器扩展（Manifest V3）：在 163 网页邮箱中**标注重点关注的发件人**，并在收到其**新邮件时弹出桌面通知**。

## 功能

- ⭐ **重点标注**：名单内发件人的邮件在列表中自动高亮 + 星标
- 📮 **新邮件提醒**：收到重点关注对象的新邮件时，弹出系统桌面通知；点击通知自动聚焦邮箱标签页
- 📇 **名单管理**：支持完整邮箱地址（`boss@company.com`）和整个域名（`@company.com`），可增删、启停、加备注，通过浏览器账号跨设备同步
- ⚡ **一键关注**：点击工具栏图标，可直接把当前列表中的发件人加入名单
- 💾 **导入导出**：名单支持 JSON 备份与恢复

## 安装

1. 克隆本仓库：
   ```bash
   git clone https://github.com/Pirates-0321/post_handle.git
   ```
2. 打开浏览器扩展管理页（`chrome://extensions` 或 `edge://extensions`）
3. 开启右上角「**开发者模式**」
4. 点击「**加载已解压的扩展程序**」，选择本仓库目录
5. 打开 [163 邮箱](https://mail.163.com/) 并登录

## 使用

1. **添加关注**：点击工具栏扩展图标 → 在「当前页面发件人」中点「＋ 关注」；或进入「管理名单」手动添加
2. **查看标注**：命中名单的邮件行会显示黄色高亮与 ★ 角标
3. **接收提醒**：新邮件到达且发件人在名单内时，系统弹出桌面通知
4. **设置**：在名单管理页可开关桌面通知、自定义高亮颜色

## 工作原理

```
mail.163.com 页面（含多层 iframe）
  └─ content script：解析邮件列表 DOM → 匹配重点名单 → 注入高亮样式
       └─ MutationObserver 监听列表变化 → 识别新到达的未读重点邮件
            └─ 消息上报 → service worker → chrome.notifications 桌面通知
名单与设置存储于 chrome.storage.sync（跨设备同步）
```

- 解析层不依赖 163 的混淆类名，采用 `title` 属性 / `mailto:` 链接等多策略启发式提取发件人地址
- 所有 DOM 选择器集中在 `src/content/selectors.js`，网易改版后只需调整该文件
- 通知按「发件人+主题+时间」去重，同一封邮件只提醒一次
- **首次打开页面只做基线扫描，不会对存量邮件批量提醒**

## 已知限制

- 需要浏览器保持 163 邮箱页面打开才会检测新邮件（扩展基于网页 DOM，不使用 IMAP）
- 163 邮箱网页结构复杂，若网易改版导致标注失效，请调整 `src/content/selectors.js`
- 切换到含旧未读邮件的文件夹时，旧邮件可能被误判为"新邮件"提醒一次（已按 key 去重，不会重复骚扰）
- 本扩展不收集、不上传任何邮箱数据，所有逻辑均在本地浏览器内完成

## 隐私与安全

- 不需要邮箱密码或授权码，仅作用于你已登录的网页界面
- 名单数据仅存于浏览器 `chrome.storage.sync`，不经过任何第三方服务器
- 仓库中不含任何凭据，可安全公开
